# ChaosCanvas

## 项目描述

ChaosCanvas 是一个基于 Vue 3 的现代化 H5 单页应用（SPA），采用企业级技术栈构建的管理后台系统。项目支持容器化部署，内置健康检测接口，适用于生产环境部署。

## 技术栈

- **前端框架**: Vue 3.5.13 + TypeScript
- **构建工具**: Vite 4.5.14
- **UI 组件库**: Element Plus 2.9.9
- **路由管理**: Vue Router
- **状态管理**: Pinia
- **开发语言**: TypeScript
- **样式预处理**: SCSS
- **代码规范**: ESLint + Prettier

## 项目类型

- **应用类型**: H5 单页应用（SPA）
- **部署方式**: 容器化静态资源部署
- **运行环境**: 支持 Docker + Kubernetes 部署
- **开发模式**: 支持开发环境和生产环境

## 核心功能

- 应用管理（列表、申请、配置）
- 发布管理（部署、合并）
- 运维管理（日志、监控）
- 系统管理（设置、版本）
- 内置健康检测接口

## 快速开始

```bash
# 安装依赖
npm install

# 开发环境
npm run start:dev

# 生产构建
npm run build:prod

# 生产预览
npm run start:prod
```
